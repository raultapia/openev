Detailed Description

Refractory period filter for event rate limiting.

Inhibits each pixel for dt time units after one of its events is accepted, so no pixel can fire faster than \( 1/dt \).

Note
T. Delbruck, R. Graca and M. Paluch, "Feedback control of event cameras"
