Detailed Description

template<typename Container, typename T>
class ev::AbstractContainer_< Container, T >

This is an auxiliary class. This class cannot be instanced.

It holds the statistics every event container offers, so that each of them only has to derive from it passing its own type:

template <typename T>
class Vector_ : public std::vector<Event_<T>>, public AbstractContainer_<Vector_<T>, T> { ... };

Note
duration(), rate(), and midTime() only need the first and the last event, so they work on containers that cannot be traversed, such as the ones built on std::queue. Those containers hide mean(), meanPoint(), and meanTime() with their own version.
